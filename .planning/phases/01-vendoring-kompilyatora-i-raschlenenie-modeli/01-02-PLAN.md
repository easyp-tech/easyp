<objective>
Prove and enforce main's position contract (1-based line, 1-based rune column, tab = 1) in the vendored protoast view model, before any rule porting begins.

Purpose: The vendored code ships protoc's convention (1-based byte columns, tab advances to next multiple of 8) while main's go-protoparser output — and therefore every lint issue users see — uses 1-based rune columns with tab counting 1. On any line with multi-byte UTF-8 or a tab before the anchor, they diverge. D-07 mandates a two-level test proof (unit + golden) so off-by-one and byte-vs-rune bugs surface NOW, in Phase 1, not during the 43-rule port in Phase 4 (research Pitfall 1, P1 detection-before-propagation).

Output: A failing-then-green TDD cycle — D-07(a) `internal/protoast/position_test.go`, D-07(b) `internal/core/position_parity_test.go`, shared fixture `internal/core/testdata/position_contract_utf8.proto`, the `builder.pos()` rune-column adaptation in `internal/protoast/build.go`, updated tab expectations in the vendored `protoast_test.go`, QF1002 fixed, divergence recorded for future syncs.
</objective>

  <behavior>
    - Pure-ASCII, space-indented lines: columns are identical to the vendored behavior (rune count == byte count when every rune is 1 byte) — no regression on the common case.
    - Line with a tab used as indentation: a declaration anchored after N tab characters gets column N+1 (tab advances by exactly 1), NOT the next multiple of 8. Case: `\t\tmessage Foo` → Column 3, not 17.
    - Line with multi-byte UTF-8 before the anchored token (inline comment between keyword and name, e.g. `message /* привет */ Foo`, or an emoji-bearing inline comment before a name token): column counts runes, not bytes. Case: a 3-rune 8-byte emoji sequence before an anchor shifts the rune column by 3 where the byte convention shifts it by 8.
    - Line numbers are unchanged by the adaptation: line starts are byte offsets; both conventions number lines identically.
    - Golden parity: for every anchor both models expose (package statement, message, field, enum, enum value, service, rpc — first-token anchors), protoast's Position.Line and Position.Column equal the legacy go-protoparser Meta.Pos values on the same fixture bytes.
  </behavior>
