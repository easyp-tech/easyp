# Быстрый старт (Quickstart)

EasyP — современный toolkit для работы с файлами Protobuf. В этом кратком руководстве вы научитесь:

1. **Инициализировать** проект с конфигурацией EasyP
2. **Настраивать линтинг**, чтобы ловить ошибки и соблюдать лучшие практики
3. **Управлять зависимостями** из Git‑репозиториев
4. **Генерировать код** из ваших Protobuf файлов

## Предварительные требования

Перед началом убедитесь, что у вас установлены:

- **EasyP CLI** — см. [руководство по установке](/docs/guide/introduction/install)
- **Git** доступен в вашем `$PATH`
- **Файлы `.proto`** (или создайте их по ходу)

Проверить версию EasyP:

```bash
easyp --version
```

## Инициализация проекта

Создайте базовый файл конфигурации `easyp.yaml` в корне проекта:

```bash
easyp init
```

Команда генерирует шаблон `easyp.yaml` с комментариями, дефолтными lint-правилами и настройками breaking-check.
`easyp init` работает интерактивно: если в корне есть `buf.yml`/`buf.yaml`, EasyP предложит миграцию; если `easyp.yaml` уже существует, попросит подтверждение перед перезаписью.

## Настройка линтинга

Линтинг помогает находить проблемы и поддерживать единый стиль. EasyP использует правила, совместимые с Buf.

Секция `lint` уже создаётся командой `easyp init`. При необходимости отредактируйте её, например так:

```yaml
lint:
  use:
    - DEFAULT
```

Запустите линтер:

```bash
easyp lint
```

Линтер проверит все `.proto` файлы и сообщит о найденных проблемах.

::: tip
Правила линтинга EasyP на 100% совместимы с Buf — мигрировать просто.
:::

## Управление зависимостями

Если вы используете сторонние protobuf пакеты (например Google APIs или gRPC Gateway), EasyP упрощает их подключение.

### Формат зависимости

Запись: `$GIT_LINK@$VERSION`

- **`$GIT_LINK`** — URL любого Git‑репозитория (GitHub, GitLab и т.д.)
- **`$VERSION`** — тег или хеш коммита (опционально)

Если версия не указана — берётся последний коммит из основной ветки.

### Добавление зависимостей

Создайте или обновите `protobuf.mod`:

```
direct (
	github.com/googleapis/googleapis                          # последний коммит
	github.com/grpc-ecosystem/grpc-gateway@v2.20.0           # конкретная версия
)
```

### Загрузка зависимостей

```bash
easyp mod download
```

Команда:
- Скачивает версии из `protobuf.lock`, если он существует
- Иначе — берёт из `protobuf.mod` и создаёт `protobuf.lock`

::: info
Совет: `easyp mod update` — игнорирует lock‑файл и подтягивает актуальные версии из `protobuf.mod`.
:::

## Генерация кода

EasyP поддерживает все стандартные protoc‑плагины.

### Конфигурация генерации

Добавьте плагины:

```yaml
lint:
  use:
    - DEFAULT
generate:
  plugins:
    - name: go
      out: .
      opts:
        paths: source_relative
    - name: go-grpc
      out: .
      opts:
        paths: source_relative
        require_unimplemented_servers: false
```

### Запуск генерации

```bash
easyp generate
```

EasyP выполнит:
1. Разрешение всех зависимостей
2. Подключение к сервису EasyP (или локальный режим)
3. Запуск указанных плагинов
4. Вывод сгенерированного кода в нужные директории

::: tip
Гибридный рантайм: WASM для скорости, Docker — для тяжёлых плагинов.
:::
